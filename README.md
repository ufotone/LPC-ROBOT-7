# LPC ROBOT 7

[English](README_EN.md) · [ダウンロード](https://github.com/ufotone/LPC-ROBOT-7/releases/latest) · [WORD一覧](WORDS.md)

KORG drumlogue用のLPC音声シンセです。58種類の単語・フレーズを、粗いロボット声として再合成します。
英語、日本語、中国語、ドイツ語、フランス語、イタリア語、ロシア語を収録しています。

**LPC ROBOT 7 v0.17.0** が現在のバージョンです。本体の表示名は **LPC ROBOT 7** です。

## インストール

1. [Releases](https://github.com/ufotone/LPC-ROBOT-7/releases/latest)から公開用ZIPをダウンロードして展開します。
2. drumlogueの電源を切り、RECを押しながら起動してUSBマスストレージ・モードにします。
3. `lpc_robot7.drmlgunit`を本体の`Units/Synths/`へコピーします。同名ファイルがある場合は置き換えます。
4. 安全に取り外し、PLAY/STOPでUSBモードを終了します。
5. MULTIトラックのUSERシンセに`LPC ROBOT 7`を選択します。

まずLEVELを低めにして確認してください。内部音声ゲインは＋18dBで、ソフトピーク制御の後にLEVELが適用されます。

## 使い方

WORDを選び、シーケンサーまたはMIDIノートで発音します。通常の再生はワンショットなので、短いゲートでも語尾まで再生します。WORDの変更は次のトリガーから反映されます。

| ページ | パラメータ | 範囲 | 初期値 | 動作 |
|---|---|---|---|---|
| 1 | WORD | 0〜57 | 0 | [58音の一覧](WORDS.md) |
| 1 | PITCH | −24〜＋50半音、RND | 0 | 再生速度と独立した音程 |
| 1 | SPEED | 25〜250%、RND | 100% | LPCパラメータの読み出し速度 |
| 1 | INDEX | OFF、0〜100%、RND | OFF | ワンショット／フリーズ／スタッター |
| 2 | LEVEL | 0〜100% | 80% | ディレイ音を含む最終音量 |
| 2 | PAN DELAY | 0〜100% | 0% | 左右へ返すディレイの量 |
| 2 | DLY TIME | 40〜750ms | 250ms | SYNC OFF時のディレイ間隔 |
| 2 | DLY FB | 0〜75% | 35% | ディレイの繰り返し量 |
| 3 | DLY SYNC | OFF / ON | OFF | ディレイを本体テンポへ同期 |
| 3 | DLY DIV | 1/32〜1/2、全10種 | 1/8 | 同期時の音符間隔 |
| 3 | STTR TIME | 20〜250ms | 80ms | INDEX RND時の音声区間長 |

PITCHとSPEEDのRNDはトリガーごとに独立して選び、その音の間は保持します。基準ノートはMIDI 60、ピッチベンドは±2半音です。

### INDEXとスタッター

- **OFF**：ワンショット再生。
- **0〜100%**：トリム後の音声のうち、音量のあるフレームを時間順に選んでフリーズ。無音区間を避けます。数値は元WAV全体の絶対位置ではありません。対応するゲート／ノートOFFで停止します。
- **RND**：トリガーごとにランダムな開始位置を選び、短い音声区間を進めて再合成し、ゲート中は同じ区間を繰り返します。各区間の間に、本体テンポの**16分音符ぶんの無音**を入れます。BPM120なら125msです。

STTR TIMEはSPEED=100%のときの区間長です。SPEED=50%では2倍の時間になります。末尾付近では区間が短くなります。無音の長さはSPEEDから独立し、DLY SYNCがOFFでもテンポに追従します。トリガーが来るたびに新しいランダム位置へ移り、ループごとには位置を選び直しません。

RNDのゲートOFFは、再生中の区間が終わってから消音します。短いゲートでも最低1区間は再生し、ゲート／ノートOFFがなければループを続けます。ディレイ使用時は、無音区間や停止後にも残響が聞こえる場合があります。数値INDEXでのフリーズ中はSPEEDは再生位置を進めません。

### ディレイとPAN

最初の返りを左、次を同じ音量で右へ返し、以後は左右の組ごとにFBの割合で減衰します。PAN DELAYを上げると中央のドライ音は少し下がります。左右の移動はヘッドホンまたはMAIN OUTPUT L/Rの両方で確認してください。

DLY DIVは`1/32, 1/16T, 1/16, 1/8T, 1/16D, 1/8, 1/8D, 1/4, 1/4D, 1/2`です。最大間隔は4秒で、超える設定では`MAX 4s`を表示します。テンポの初期値はBPM120で、本体からの通知に追従します。

出力PANは本体のMIX ROUTE側で調整してください。PAN DELAYはディレイ量の設定です。

## ビルドと検証

Dockerを起動して、Windowsでは`./build.ps1`、Linux/macOSでは`sh build.sh`を実行します。出力は`dist/lpc_robot7.drmlgunit`です。ビルド用SDKコンテナはdigestで固定しています。TTSモデルや元WAVはビルドに不要です。

ネイティブLinuxでのテストは`sh tests/run.sh`、AddressSanitizer / UndefinedBehaviorSanitizer付きは`SANITIZE=1 sh tests/run.sh`。テストの一時出力は`.test-output/`に作成します。

実機動作確認済み。ユニットAPI 1.0.0を要求します。

私用開発者ID `0x5534544E`、ユニットID `0x4C504337`を使用しています。
